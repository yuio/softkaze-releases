# Softkaze releases

Downloads of the applications of [Softkaze](https://softkaze.com) for Linux and macOS. Each release is one version of one
application: its tag is `application-vVERSION`, and its files are named `Application-VERSION-system-architecture`.

## TodoMarkdown

A classic, feature-rich, keyboard-friendly to-do list editor, ready to work alongside your AI. Lists are plain Markdown
text files. No account, no cloud.

- **Windows**: [Microsoft Store](https://apps.microsoft.com/detail/9NP39WTPB45T)
- **Linux**: [TodoMarkdown 1.2](https://github.com/yuio/softkaze-releases/releases/tag/todomarkdown-v1.2), as a `.deb`
  for Debian and Ubuntu, or an `.AppImage` for any distribution
- **macOS**: coming soon
